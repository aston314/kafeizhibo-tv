# 球赛直播

球赛直播是一款为电视大屏设计的体育赛事直播应用。打开应用后，可以用遥控器方向键或鼠标浏览赛事、移动焦点并开始观看，界面会根据电视分辨率自动适配。

## 可以做什么

- 首页集中展示正在直播的比赛，减少进入页面后的查找步骤。
- 按直播、赛程和录像回放浏览内容，也可以按足球、篮球、网球、台球等分类筛选。
- 同时接入咖啡直播和豆包直播。不同来源会统一显示在赛事列表中，进入比赛后可以选择可用的直播线路或解说源。
- 播放页以视频为中心，支持播放、暂停、线路切换、全屏和失败重试；直播加载或切换线路时会显示清晰的加载状态。
- 适配电视遥控器焦点操作，也支持鼠标移动和点击。获得焦点的卡片、按钮和导航项会保持高亮，方便在远距离观看。
- 提供打赏页面，支持查看微信和支付宝二维码。

应用不提供会员、账号和付费内容功能。

## 使用方式

从[球赛直播发布页](https://github.com/aston314/kafeizhibo-tv/releases/latest)下载并安装到 Android TV 或电视盒子。启动后等待赛事列表加载，使用方向键移动焦点，按确认键进入比赛；在播放页按确认键显示播放控制，按返回键返回列表。

赛事数据和直播线路来自接入的直播来源，具体比赛数量和可用线路会随来源实时变化。某个来源暂时不可用时，其他来源仍会继续显示；播放失败时可以在页面上直接重试或切换线路。

## 版本更新

打开应用侧栏中的“设置”，选择“检查版本更新”。应用会自动选择可用的连接方式；下载完成后会验证安装包，并打开 Android 系统安装界面。
